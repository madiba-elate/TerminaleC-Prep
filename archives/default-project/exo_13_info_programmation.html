Partie 2 — Programme C : Volume d'une sphère

C
Énoncé : Écrire un programme en C qui calcule et affiche le volume d'une sphère. Le rayon R est lu au clavier.
Formule :
V = (4/3) × π × R³
Programme C :
#include <stdio.h>

int main() {
    const float PI = 3.14;
    float R, V;
    printf("Rayon (m) : ");
    scanf("%f", &R);
    V = (4.0/3.0) * PI * R * R * R;
    printf("Volume = %.2f m³\n", V);
    return 0;
}
V = (4/3) × 3.14 × R³Lecture clavier : scanf("%f", &R)
⭐ Modifications :
• const float PI = 3.14 → constante à 2 décimales (pas #define)
• const = la valeur ne peut pas être modifiée après déclaration
• #define est remplacé par const → plus sûr et typé
• Le rayon R est lu (valeur inconnue) → programme interactif

Partie 3 — Algorithme : Moyenne des notes de la classe

Algorithme
Énoncé : Enregistrer les notes d'informatique d'une classe de 1ère C dans une structure de données (tableau), puis calculer et afficher la moyenne générale.
Algorithme (pseudocode) :
Algorithme MoyenneClasse

Variables :
    N        : entier   (nombre d'élèves)
    Notes[]  : tableau de réels (notes)
    Somme    : réel
    Moyenne  : réel
    i        : entier

Début
    Écrire("Nombre d'élèves : ")
    Lire(N)

    Tableau Notes[1..N]  ← structure de données

    POUR i DE 1 À N
        Écrire("Note de l'élève ", i, " : ")
        Lire(Notes[i])
    FIN POUR

    Somme ← 0
    POUR i DE 1 À N
        Somme ← Somme + Notes[i]
    FIN POUR

    Moyenne ← Somme / N

    Écrire("Moyenne générale de la classe : ", Moyenne)
Fin
Structure de données utilisée :
Tableau unidimensionnel : Notes[1..N]
• Notes[i] = note du i-ème élève (1 ≤ i ≤ N)
• Somme = Σ Notes[i] (de i=1 à N)
• Moyenne = Somme / N
Moyenne = Somme / N
Stockée dans un tableau Notes[] de taille N
⭐ Différences clés :
• Algorithmique = plan logique (pseudocode)
• Programmation C = code exécutable
• Structure de données = tableau pour organiser les notes
• Classeur = alternative avec Excel (même calcul via SOMME()/NB())
