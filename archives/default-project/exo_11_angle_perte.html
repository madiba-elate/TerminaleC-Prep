📚 Exercice 11 — Angle de perte

tg α = 2πRCf • Addition des IR

Exo 11 — Angle de perte d'un condensateur

PHYSIQUE
Données : tg α = 2πRCf
R = 4500 kΩ à 1%  |  C = 3300 pF à 0,5%  |  f = 1000 Hz à 2%
1) Calcul de tg α :
tg α = 2πRCf
R = 4,5×10⁶ Ω
C = 3,3×10⁻⁹ F
f = 10³ Hz

tg α = 2π × 4,5×10⁶ × 3,3×10⁻⁹ × 10³
= 6,28 × 14,85
= 93,3
2) Incertitude relative (produit → on additionne) :
IR = IR_R + IR_C + IR_f
IR_R = 1 %
IR_C = 0,5 %
IR_f = 2 %
IR_total = 1 + 0,5 + 2 = 3,5 %
3) Incertitude absolue :
Δ(tg α) = IR × tg α
Δ(tg α) = 0,035 × 93,3 = 3,3 ≈ 3
tg α = (93 ± 3)IR = 3,5 %
La valeur absolue a 2 ch. sig. → (93 ± 3)
⭐ Règle : pour un produit A×B×C → IR_total = IR_A + IR_B + IR_C
On ne convertit pas les pourcentages en absolues avant d'additionner.
Le maillon faible est f (2%).
Résultat final : tg α = (93 ± 3)
