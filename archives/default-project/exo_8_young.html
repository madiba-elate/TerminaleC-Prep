📚 Exercice 8 — Interfrange d'Young

λ = 532 nm • D = 2,150 m • a = 100 μm • k = 2

Exo 8 — Interfrange de Young

PHYSIQUE
Énoncé : i = λD/a avec λ = (532 ± 1) nm, D = (2,150 ± 0,005) m, a = (100 ± 1) μm.
Incertitudes à 95%. Déterminer i = (m ± Δm) mm.
1) Valeur nominale :
i = λD / a
i = (532×10⁻⁹ × 2,150) / (100×10⁻⁶)
= 1,1438×10⁻⁶ / 10⁻⁴
= 0,011438 m
= 11,44 mm
2) Incertitudes relatives (produit/quotient → on additionne) :
IR_λ = Δλ/λ = 1/532 = 0,19 %
IR_D = ΔD/D = 0,005/2150 = 0,23 %
IR_a = Δa/a = 1/100 = 1,00 % ← maillon faible

IR_total = 0,19 + 0,23 + 1,00 = 1,42 %
3) Incertitude absolue :
Δi = IR_total × i
Δi = 0,0142 × 11,44 = 0,162 ≈ 0,16 mm
i = (11,44 ± 0,16) mmou (11,4 ± 0,2) mm
⭐ Règle : pour i = λD/a → IR = IR_λ + IR_D + IR_a
Le maillon faible (a, 1%) domine l'incertitude finale.
Résultat : i = (11,44 ± 0,16) mm
