📚 Exercice 10 — Résistances & Énergie

Série / Parallèle • Énergie thermique • Propagation d'incertitudes

Partie 1 — Résistances en série et parallèle

PHYSIQUE
Données : R1 = (10,7 ± 2) Ω ; R2 = (26,5 ± 0,5) Ω
1a) En série :
R_s = R1 + R2
R_s = 10,7 + 26,5 = 37,2 Ω
ΔR_s = ΔR1 + ΔR2 = 2 + 0,5 = 2,5 Ω
(on additionne les incertitudes absolues)
1b) En parallèle :
R_p = R1 × R2 / (R1 + R2)
R_p = 10,7 × 26,5 / 37,2 = 7,6 Ω
IR_R1 = 2/10,7 = 18,7 %
IR_R2 = 0,5/26,5 = 1,9 %
IR_Rp = 18,7 + 1,9 = 20,6 %
ΔR_p = 0,206 × 7,6 ≈ 1,6 Ω
Série : R = (37,2 ± 2,5) ΩIR = 2,5/37,2 = 6,7 %
Parallèle : R = (7,6 ± 1,6) ΩIR = 20,6 %
⭐ Règles :
• Somme → on additionne les Δ absolues
• Produit/Quotient → on additionne les IR relatives
• Le maillon faible R1 (2/10,7 = 19%) domine le parallèle

Partie 2 — Énergie thermique

PHYSIQUE
Données : R = 5,1 Ω ; t = 60 s ; I = 2,2 A
Formule : E = I² R t
Règle : incertitudes absolues au plus = 1 unité du dernier chiffre
1) Énergie thermique :
E = I² × R × t
E = 2,2² × 5,1 × 60 = 4,84 × 306
= 1 481 J ≈ 1,5 × 10³ J (2 ch. sig.)
2) Incertitudes (1 unité du dernier chiffre) :
I = 2,2 A → ΔI = 0,1 A
R = 5,1 Ω → ΔR = 0,1 Ω
t = 60 s → Δt = 1 s
3) Incertitude relative :
IR_E = 2×IR_I + IR_R + IR_t
IR_I = 0,1/2,2 = 4,5 %
IR_R = 0,1/5,1 = 2,0 %
IR_t = 1/60 = 1,7 %
IR_E = 2×4,5 + 2,0 + 1,7 = 12,7 %
4) Incertitude absolue :
ΔE = 0,127 × 1481 ≈ 190 J ≈ 2 × 10² J
E = (1,5 ± 0,2) × 10³ JIR ≈ 13 %
