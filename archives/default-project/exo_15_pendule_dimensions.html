📚 Exercice 15 — Pendule & Dimensions

Analyse dimensionnelle • Pendule simple • Validité des formules

Partie 1 — Période du pendule simple

PHYSIQUE
Énoncé : Pendule simple : masse m, fil de longueur l, pesanteur g. Montrer par analyse dimensionnelle que T = K√(l/g).
1.1 — Analyse dimensionnelle :
Hypothèse : T dépend de l et g (pas de m, car m ne doit pas intervenir).
On pose : T = K · la · gb
[T] = [l]a · [g]b
T = La · (L·T-2)b = La+b · T-2b

Identification des exposants :
• Pour T : 1 = -2b → b = -1/2
• Pour L : 0 = a + b → a = 1/2
T = K · l1/2 · g-1/2 = K · √(l/g)
T = K · √(l/g)K est une constante sans dimension (K = 2π pour un petit angle)
1.2 — Remarque sur T :
T ne dépend PAS de la masse m !
T ne dépend que de l (longueur) et g (pesanteur). Tous les objets oscillent avec la même période, quelle que soit leur masse.

Partie 2.1 — F = Gm/r : Valide ?

PHYSIQUE
Énoncé : F = G·m/r avec [G] = m³·kg⁻¹·s⁻². Valider dimensionnellement.
Dimensions connues :
[F] =
M¹·L¹·T-2
(force)
[G] =
M-1·L³·T-2
(donné)
[m] = M
[r] = L
Analyse du membre de droite :
[G·m/r] = [G] · [m] / [r]
[G·m/r] = (M-1·L³·T-2) · M · L-1
= M-1+1 · L3-1 · T-2
= M0 · L² · T-2
= L²·T-2
Comparaison :
[F] attendu : M¹·L¹·T-2
[Gm/r] trouvé : L²·T-2
DIFFÉRENT !
❌ F = Gm/r n'est PAS dimensionnellement valide !
La formule correcte est F = G·m₁·m₂/r² (loi de Newton). Vérification : [G·m₁·m₂/r²] = M·L·T⁻² = [F] ✓

Partie 2.2 — P = r·g·h₁ + h₂·F : Valide ?

PHYSIQUE
Énoncé : P = r·g·h₁ + h₂·F
P = pression, g = accélération, h₁, h₂ = hauteurs, r = longueur, F = force
Dimensions connues :
[P] =
M¹·L-1·T-2
(pression = F/S)
[F] =
M¹·L¹·T-2
(force)
[r] = L
[g] = L·T-2
[h₁] = L
[h₂] = L
Analyse du terme 1 : r·g·h₁
[r·g·h₁] = L · (L·T-2) · L = L³·T-2
≠ [P] = M·L-1·T-2 ❌
Analyse du terme 2 : h₂·F
[h₂·F] = L · (M·L·T-2) = M·L²·T-2
≠ [P] = M·L-1·T-2 ❌
Vérification supplémentaire :
Les deux termes ont des dimensions DIFFÉRENTES entre eux :
• Terme 1 = L³·T-2
• Terme 2 = M·L²·T-2

→ On ne peut même pas les ADDER (incohérence interne !)
❌ P = r·g·h₁ + h₂·F n'est PAS dimensionnellement valide !
1) Aucun des 2 termes n'a la dimension d'une pression [P] = M·L-1·T-2
2) Les 2 termes n'ont pas la même dimension → ils ne peuvent pas être additionnés
3) La formule correcte pour la pression hydrostatique est P = ρ·g·h (avec ρ = densité, pas une longueur)
⭐ Méthode :
• Développer chaque terme séparément
• Vérifier que [chaque terme] = [le membre de gauche]
• Vérifier que TOUS les termes ont la MÊME dimension (sinon on ne peut pas les additionner)
• Si l'une de ces conditions échoue → formule INVALIDE
