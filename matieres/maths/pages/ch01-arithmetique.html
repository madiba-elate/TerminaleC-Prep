1️⃣ Bases : ℕ, ℤ, divisibilité
a∣b ⟺ ∃q ∈ ℤ, b = aq. Axiomes ℕ : plus petit élément, plus grand (majorée), suites décroissantes finies.

5 théorèmes : (1) a∣b ⇒ a∣bc · (2) transitivité · (3) a∣b,a∣c ⇒ a∣(αb+βc) · (4) ∣a∣≤∣b∣ · (5) a∣b,b∣a ⇒ a=±b.

Premier : ≠1, diviseurs 1 et lui-même. 0 et 1 NON premiers. Si n=p×q, p≤q ⇒ p≤√n.
2️⃣ Division euclidienne (démonstration exigible)
a = bq + r avec 0 ≤ r < b (dans ℤ : 0 ≤ r < |b|) — couple (q,r) UNIQUE
Unicité : r₁−r₂ = multiple de b, or −b < r₁−r₂ < b ⇒ = 0, puis q₁=q₂. Dividende a, diviseur b, quotient q, reste r.
3️⃣ Congruences
a ≡ b [n] ⟺ n∣(a−b) (même reste)

Compatibles : +, −, ×, puissances. Ex : 10≡1[3] ⇒ 10ᵏ≡1[3].

Critères : 2 (pair) · 5 (0/5) · 3 et 9 (somme des chiffres) · 11 (somme alternée). Ex : 456 → 4+5+6=15 → divisible par 3.
4️⃣ PGCD, Euclide, Bézout, Gauss
PGCD = plus grand élément de D(a)∩D(b). Euclide = dernier reste non nul. Ex : 64=48+16, 48=16×3 → 16.
Bézout : pgcd=d ⟺ ∃u,v : au+bv=d · Gauss : a∣bc et a∧b=1 ⇒ a∣c

Ex : 44 = (−2)×25872 + 107×484 (remontée d'Euclide). Conséquences : ab∣c (premiers entre eux), p∣ab ⇒ p∣a ou p∣b.

5️⃣ Diophantiennes + PPCM

ax+by=c : ① d=pgcd divise c ? ② simplifier ③ Bézout → (x₀,y₀) ④ Gauss → générales.

9x+6y=15 → 3x+2y=5 → (15,−20) → x=15+2k, y=−20−3k
pgcd(a,b) × ppcm(a,b) = ab — Ex : ppcm(12,15)=60
6️⃣ Premiers : test, infinité, décomposition, bases

Test : n premier si aucun premier ≤ √n ne le divise (409 : √≈20,2 → testé 2..19 → premier).

Infinité (absurde) : p₁…pₙ+1 a un diviseur premier hors liste. Décomposition unique (admise) : 60=2²·3·5 → diviseurs, PGCD, PPCM.

Ératosthène : rayer multiples de 2,3,5… jusqu'à p²>N. Bases : écriture unique, binaire (1001₂ se lit chiffre à chiffre).

📝 Démonstrations exigibles — à savoir rédiger
Divisibilité (Th.1-3) : b=aq ⇒ bc=a(qc) · b=aq,c=br ⇒ c=a(qr) · αb+βc=a(αq+βr). ∎
Euclide, existence : Archimède ⇒ bq ≤ a < b(q+1) ⇒ r=a−bq. Fin : E={n: nb>a} non vide → plus petit élément p → (p−1)b ≤ a < pb.
Congruences : a=nq+r, b=nq′+r′ ⇒ a−b=n(q−q′)+(r−r′), −n<r−r′<n : même reste ⟺ n∣(a−b). Compatibilité : a−a′=nq, b−b′=nq′ ⇒ sommes, différences, produits (ab=n(…)+a′b′), puissances par récurrence. ∎
Bézout : E={na+mb}, E∩ℕ*∋a → plus petit élément d=au+bv ; tout x=dq+r (r∈E ⇒ r=0) → multiples de d ; d′=pgcd∣d et d∣d′ ⇒ d=d′. Corollaire : pgcd=1 ⟺ au+bv=1. ∎
Gauss : bc=ka, au+bv=1 → ×c : auc+bcv=c → c=a(uc+kv). ∎ Infinité des premiers : p₁…pₙ+1 a un diviseur premier q hors liste (sinon q∣1). ∎
🔍 Euclide détaillé + critère 3 + décomposition

Double inclusion (étape 1) : c∣a,c∣b ⇒ c∣a−bq₀=r₀ · réciproque : c∣b,c∣r₀ ⇒ c∣bq₀+r₀=a. Étape 3 : D(0)=ℕ. Remontée : 44=(−2)×25872+107×484.

Critère 3 général : 10≡1[3] ⇒ 10ᵏ≡1[3] ⇒ n ≡ somme de ses chiffres [3]. 456 : 4+5+6=15 ✓. Par 5 (dernier chiffre), 9 (somme), 11 (somme alternée).

Décomposition : existence par suites (pᵢ),(aᵢ) décroissantes → 60=2²·3·5, 4896=17·3²·2⁵. Usages : diviseurs, carrés, PGCD, PPCM. Ératosthène : rayer multiples de 2,3,5… jusqu'à p²>N.

def estPremier(n): k=2
while k*k<=n:
  if n%k==0: return False
  k+=1
return True
def pgcd(a,b):
  r=a%b
  while r!=0: a,b=b,r; r=a%b
  return b
