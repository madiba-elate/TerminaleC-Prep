## 🎯 L'essentiel en 5 lignes

1. A **job interview** = a formal meeting between the applicant and the employer to discuss qualifications, skills and experience.
2. Key people: **applicant/candidate** (seeks the job) vs **employer/boss** (offers it) ; **employee/worker** (hired).
3. Key assets: **qualification, competence, aptitude, ability, know-how, experience, certificate, diploma, achievements**.
4. Key actions: **recruit/employ/engage**, **resign** (= leave/quit), **apply** (= formal request).
5. Key qualities: **punctual** (on time), **trustworthy** (honest), good **references**.

## 📖 Cours optimisé

### 1. Speaking — Discuss about the job interview

**Definition:** A job interview is a formal meeting between the job applicant and
the employer (or interviewer) to discuss the applicant's qualifications, skills
and experiences for the job.

### 2. Essential knowledge — Vocabulary

| Word | Synonyms / Meaning |
|---|---|
| Candidate, applicant, job seeker | person who applies for a job |
| Employer (boss, manager, director) | person who offers the job |
| Employee (worker) | person who is hired |
| Qualification, competence, aptitude, ability, know-how | what you can do |
| Experience, skills, knowledge | what you have done / learned |
| Certificate, diploma | proof of studies |
| CV | document presenting all the above |
| Requirements, needs, necessities | what the job demands |
| Recruit (enrol, engage, employ) | to hire someone |
| Position (job, post, function) | the work itself |
| Punctual | on time / timely / early |
| Achievements | accomplishments, success, awards |
| Reference | recommendation, testimonial |
| Application | a formal request for a job |
| Resign | leave / quit / abandon / give up |
| Trustworthy | honest and truthful |
