**Ex. 2 — Oxydation et redox (8 pts) :** trois tubes (A : primaire, B : secondaire,

a) Observations couleur par tube. b) Produits formés (A, B, C).
c) Écris les demi-équations (A : 2 étapes ; B : 1 étape).

**Ex. 3 — Déshydratation (4 pts) :** chauffage du butan-2-ol avec H₂SO₄ concentré.
a) Équation générale. b) Produit(s) possible(s) + majoritaire (règle ?).

## ✅ Corrigés

### Ex. 1
a) **Primaire : éthanol** (1 C voisin) · b) **Secondaire : propan-2-ol** ·
c) **Tertiaire : 2-méthylpropan-2-ol** · d) **Secondaire : butan-2-ol**.
(1 pt par réponse complète classe + nom.)

### Ex. 2
a) A et B : **orange → vert** (Cr₂O₇²⁻ → Cr³⁺) ; C : **reste orange** (rien).
b) A : **aldéhyde** (puis acide si excès) ; B : **cétone** ; C : **rien**.
c) A : R–CH₂OH → R–CHO + 2H⁺ + 2e⁻ ; R–CHO + H₂O → R–COOH + 2H⁺ + 2e⁻.
   B : R₂CH–OH → R₂C=O + 2H⁺ + 2e⁻.
d) Couleur verte + aldéhyde/acide = **primaire** ; verte + cétone = **secondaire** ;
   pas de changement = **tertiaire**.

### Ex. 3
a) **Butan-2-ol → alcène + H₂O** (H₂SO₄ conc., chaud).
b) Possibles : **but-1-ène** + **but-2-ène** ; majoritaire : **but-2-ène**
   (règle de **Zaïtsev** : alcène le plus substitué).

> ⭐ Phrases qui rapportent : « le tertiaire **résiste à l'oxydation** » /
> « orange → vert : Cr₂O₇²⁻ réduit en Cr³⁺ » / « **Zaïtsev** : le plus substitué ».
