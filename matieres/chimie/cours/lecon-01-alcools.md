## 🎯 L'essentiel en 5 lignes

1. Un **alcool** = R–OH (groupe –OH sur carbone tétraédrique) ; **3 classes** : primaire (C lié à 1 C), secondaire (2 C), tertiaire (3 C).
2. **Sodium** : 2 R–OH + 2 Na → 2 R–ONa (alcoolate) + H₂↑ — test de **tous** les alcools.
3. **Oxydation** (KMnO₄, K₂Cr₂O₇) : primaire → aldéhyde → **acide** ; secondaire → **cétone** ; tertiaire → **rien**.
4. Couleurs : MnO₄⁻ **violet → incolore**, Cr₂O₇²⁻ **orange → vert**.
5. **Déshydratation** (H₂SO₄ conc., chaud) : alcool → **alcène** + H₂O.

## 📖 Cours complet

### 1. Ce qu'est un alcool — classes et noms

- **Définition** : molécule avec un groupe hydroxyle **–OH** porté par un carbone
  **tétraédrique** (4 liaisons simples). Formule générale : **R–OH**.
- **Classes** (compte les carbones liés au carbone qui porte –OH) :
  - **Primaire** : 1 seul C voisin → ex : éthanol CH₃–CH₂OH.
  - **Secondaire** : 2 C voisins → ex : propan-2-ol CH₃–CH(OH)–CH₃.
  - **Tertiaire** : 3 C voisins → ex : 2-méthylpropan-2-ol (CH₃)₃C–OH.
- **Nom** : nom de l'alcane + suffixe **-ol** + numéro de position du –OH
  (ex : butan-2-ol). Retiens juste : *le –OH donne son nom et sa place*.

### 2. Propriété n°1 — Acidité : réaction avec le sodium

- Équation : **2 R–OH + 2 Na → 2 R–ONa + H₂↑** (R–ONa = ion **alcoolate**).
- Observations : effervescence (H₂), disparition du sodium.
- Points BAC : les alcools sont des acides **très faibles** (pKa ≈ 16-18, plus
  faibles que l'eau) → **pas de réaction avec la soude NaOH diluée**.
  Le sodium les révèle **tous les trois** (primaire, secondaire, tertiaire).

### 3. Propriété n°2 — Oxydation ménagée (LE CŒUR DU CHAPITRE)

- **Oxydants** : permanganate **MnO₄⁻** (violet) ou dichromate **Cr₂O₇²⁻** (orange),
  en milieu acide.
- **Tableau à savoir par cœur** :

| Classe | Oxydant en défaut | Oxydant en excès |
|---|---|---|
| **Primaire** R–CH₂OH | **Aldéhyde** R–CHO | **Acide carboxylique** R–COOH |
| **Secondaire** R₂CH–OH | **Cétone** R₂C=O (même en excès) | idem |
| **Tertiaire** R₃C–OH | **RIEN** (résiste) | RIEN |

- **Demi-équations** (à savoir écrire) :
  - R–CH₂OH → R–CHO + 2 H⁺ + 2 e⁻
  - R–CHO + H₂O → R–COOH + 2 H⁺ + 2 e⁻
  - R₂CH–OH → R₂C=O + 2 H⁺ + 2 e⁻
- **Couleurs** (couples redox) : MnO₄⁻/Mn²⁺ : **violet → incolore** ;
  Cr₂O₇²⁻/Cr³⁺ : **orange → vert**.
- Exemple complet : éthanol + excès KMnO₄ → acide éthanoïque (acide acétique).

### 4. Propriété n°3 — Déshydratation : alcool → alcène

- Conditions : **H₂SO₄ concentré, chaud** (≈ 180 °C pour l'éthanol).
- Équation type : **CH₃–CH₂OH → CH₂=CH₂ + H₂O** (éthène).
- Règle de **Zaïtsev** : si plusieurs alcènes possibles, le **plus substitué**
  (le plus stable) est majoritaire (ex : butan-2-ol → but-2-ène majoritaire).

### 5. Propriété n°4 — Combustion complète

- **CₓHᵧO + …O₂ → x CO₂ + (y/2) H₂O** — ex : biocarburant (éthanol E85).

### 6. Tests et identification (ce que le BAC adore)

1. **Sodium → H₂** : prouve un alcool (mais pas sa classe).
2. **Oxydation** : primaire → aldéhyde/acide ; secondaire → cétone ;
   **tertiaire → rien** → la classe est identifiée.
3. Bonus : l'**aldéhyde** formé (primaire) se reconnaît à la liqueur de
   **Fehling** (précipité rouge) ou au réactif de **Tollens** (miroir d'argent).

### 7. Alcools de la vie courante

- **Éthanol** : boissons, désinfectant, carburant.
- **Méthanol** : solvant, **toxique** (cécité) — jamais dans les boissons.
- **Glycérol** (propane-1,2,3-triol) : cosmétiques, explosifs (nitroglycérine).

## 📐 Repères clés

| Élément | Contenu |
|---|---|
| Classes | 1 C voisin = I · 2 = II · 3 = III |
| Na | alcoolate + H₂ (les 3 classes) |
| Oxydation | I → aldéhyde → acide · II → cétone · III → rien |
| Couleurs | violet→incolore · orange→vert |
| Déshydratation | H₂SO₄ chaud → alcène + H₂O (Zaïtsev) |

## ⭐ Tombe souvent aux devoirs

- Classer + nommer 3-4 alcools (formules semi-développées).
- Prévoir le produit d'oxydation selon la classe + justifier.
- Équilibrer une redox (demi-équations + couleurs observées).
- Identifier un alcool inconnu par tests successifs (Na puis oxydation).
- Déshydratation : produit majoritaire (Zaïtsev).
