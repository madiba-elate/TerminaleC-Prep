1️⃣ Alcool : classes & noms (la base)
Alcool = R–OH : groupe –OH sur carbone tétraédrique. Classe = nombre de carbones voisins du C porteur : I (1 C) · II (2 C) · III (3 C).
Primaire : CH3–CH2OH (éthanol) · Secondaire : CH3–CH(OH)–CH3 (propan-2-ol) · Tertiaire : (CH3)3C–OH

Nom = alcane + -ol + position du –OH (ex : butan-2-ol).

2️⃣ Acidité — le test au sodium
2 R–OH + 2 Na → 2 R–ONa (alcoolate) + H2↑

Effervescence (H2). Acides très faibles (pKa ≈ 16-18) → pas de réaction avec NaOH diluée. Révèle les 3 classes.

3️⃣ Oxydation — LE tableau à savoir par cœur

Oxydants : KMnO4, K2Cr2O7 (milieu acide).

ClasseOxydant en défautOxydant en excès
Primaire R–CH2OHAldéhyde R–CHOAcide R–COOH
Secondaire R2CH–OHCétone R2C=O
Tertiaire R3C–OHRIEN (résiste)
R–CH2OH → R–CHO + 2H+ + 2e− · R–CHO + H2O → R–COOH + 2H+ + 2e−
R2CH–OH → R2C=O + 2H+ + 2e−
MnO4− violet → incolore (Mn2+)
Cr2O72− orange → vert (Cr3+)
4️⃣ Déshydratation + combustion
CH3–CH2OH → CH2=CH2 + H2O (H2SO4 conc., ≈180 °C)
Zaïtsev : l'alcène le plus substitué est majoritaire (butan-2-ol → but-2-ène).

Combustion complète : alcool + O2 → CO2 + H2O (biocarburant).

5️⃣ Identifier un inconnu (méthode BAC)
  1. Sodium → H2 : c'est un alcool (classe inconnue).
  2. Oxydation : aldéhyde/acide = I · cétone = II · rien = III.
  3. Bonus : aldéhyde → Fehling (rouge) ou Tollens (miroir).
✍️ 3 exercices types BAC + corrigés

Ex.1 Classe + nomme : éthanol (I) · propan-2-ol (II) · 2-méthylpropan-2-ol (III) · butan-2-ol (II).

Ex.2 3 tubes + K2Cr2O7 : A,B orange→vert, C inchangé. A = aldéhyde/acide → I · B = cétone → II · C = rien → III.

✅ Demi-équations de l'Ex.2

A : R–CH2OH → R–CHO + 2H+ + 2e− ; R–CHO + H2O → R–COOH + 2H+ + 2e−. B : R2CH–OH → R2C=O + 2H+ + 2e−.

Ex.3 Butan-2-ol + H2SO4 chaud → but-1-ène + but-2-ène majoritaire (Zaïtsev).
