📚 Exercice 16 — Unités SI & Homogénéité

Newton • Constante G • Kepler • Poids • Réacteur

1 — Le Newton en SI

PHYSIQUE
Énoncé : F = ma, a en m·s⁻². Exprimer le Newton en SI.
Analyse dimensionnelle :
[F] = [m] · [a]
[F] = kg · m·s-2
= kg·m·s-2
1 N = 1 kg·m·s-2
Le Newton est l'unité SI de force, dérivée des unités de base (kg, m, s)

2 — Unité SI de la constante G

PHYSIQUE
Énoncé : F = G·m₁·m₂/d². Déduire l'unité SI de G.
Isoler G :
G = F·d² / (m₁·m₂)
Substitution des dimensions :
[G] = [F]·[d²] / ([m₁]·[m₂])
= (kg·m·s-2) · m² / (kg · kg)
= kg1·m³·s-2 / kg2
= m³·kg-1·s-2
[G] = m³·kg⁻¹·s⁻²
G = 6,674 × 10⁻¹¹ m³·kg⁻¹·s⁻²

3 — Relation entre T, R, Mₛ et G

PHYSIQUE
Énoncé : Les planètes tournent autour du soleil en temps T à la distance R. Trouver la relation la plus simple entre T, R, Mₛ et G.
Hypothèse : T = k·R^a·Mₛ^b·G^c
[T] = [R]a·[Mₛ]b·[G]c
T = La · Mb · (M-1·L³·T-2)c
= Mb-c · La+3c · T-2c
Identification :
T : 1 = -2c → c = -1/2
M : 0 = b-c → b = -1/2
L : 0 = a+3c → a = 3/2
T = k · R3/2 · Mₛ-1/2 · G-1/2 = k · √(R³ / (G·Mₛ))
T = 2π · √(R³ / (G·Mₛ))
Loi de Kepler III (avec k = 2π)
⭐ Remarque :
• T² = 4π²R³/(G·Mₛ) → T² ∝ R³
• Plus une planète est loin, plus sa période est longue
• La masse du soleil Mₛ est dans le dénominateur → plus Mₛ est grand, plus T est court

4 — Unité SI de g (intensité du champ de pesanteur)

PHYSIQUE
Énoncé : Poids P = m·g. Trouver l'unité SI de g.
Expression de g :
g = P / m
[g] = [P] / [m]
= (kg·m·s-2) / kg
= m·s-2
[g] = m·s⁻²
Même dimension qu'une accélération ! c'est normal : le champ de pesanteur = accélération gravitationnelle

6 — Le produit D·V est-il homogène à une force ?

PHYSIQUE
Énoncé : D = 29×10² kg·s⁻¹, V = 4,0×10³ m·s⁻¹. Montrer que D·V est homogène à une force.
Dimensions :
[D] =
M¹·T-1
(débit massique)
[V] =
L¹·T-1
(vitesse)
Produit :
[D·V] = [D] · [V]
[D·V] = (kg·s-1) · (m·s-1)
= kg·m·s-2
= [F] = M¹·L¹·T-2
✅ D·V est homogène à une FORCE !
[D·V] = kg·m·s⁻² = [F] = 1 N
Valeur numérique :
D·V = 2900 × 4000 = 1,16 × 10⁷ N ≈ 11,6 MN
C'est la poussée du réacteur de l'avion !
⭐ Physique : La force de propulsion d'un réacteur = débit massique × vitesse d'éjection des gaz.
C'est la conservation de la quantité de mouvement : F = Δp/Δt = (Δm/Δt)·v = D·V
