📚 Exercice 18 — Fréquence d'une goutte d'eau

Analyse dimensionnelle • Tension superficielle • Exposants

Énoncé

PHYSIQUE
Données : f = k₁·R^a·ρ₀^b·A^c

Paramètres :
• f = fréquence de vibration de la goutte
• R = rayon de la goutte
• ρ₀ = masse volumique de l'eau (inertie)
• A = constante de tension superficielle (force par unité de longueur)

Rappel : La tension superficielle = force par unité de longueur

Étape 1 — Dimensions des grandeurs

PHYSIQUE
[f] = T⁻¹ — fréquence (s⁻¹)
[R] = L — rayon (m)
[ρ₀] = M·L⁻³ — masse volumique (kg·m⁻³)
[A] = M·T⁻² — force/longueur = (kg·m·s⁻²)/m = kg·s⁻²
f = k₁ · Ra · ρ₀b · Ac

Étape 2 — Identification des exposants

PHYSIQUE
Équation dimensionnelle complète :
[f] = [R]a · [ρ₀]b · [A]c
T-1 = La · (M·L-3)b · (M·T-2)c
= Mb+c · La-3b · T-2c
Identification des exposants :
Temps (T) :
-1 = -2c
c = 1/2
Masse (M) :
0 = b + c
b = -c
b = -1/2
Longueur (L) :
0 = a - 3b
a = 3b
a = -3/2
a = -3/2 ; b = -1/2 ; c = 1/2

Étape 3 — Expression finale

PHYSIQUE
Substitution dans f = k₁·R^a·ρ₀^b·A^c :
f = k₁ · R-3/2 · ρ₀-1/2 · A1/2
f = k₁ · √A / (R3/2 · √ρ₀)
= k₁ · √(A/ρ₀) / R3/2
Vérification dimensionnelle :
[√(A/ρ₀)] = √(M·T-2/(M·L-3))
= √(L³·T-2) = L3/2·T-1

[f] = L3/2·T-1 / L3/2 = T⁻¹ ✓
✅ Vérification OK !
f = k₁ · √(A/ρ₀) / R^(3/2)
⭐ Interprétation physique :
• Plus le rayon R est grand → f diminue (grosse goutte vibre plus lentement)
• Plus la tension superficielle A est forte → f augmente (goutte plus "rigide")
• Plus la densité ρ₀ est grande → f diminue (plus d'inertie → vibration plus lente)
• Ce résultat correspond à la fréquence de Rayleigh des oscillations d'une goutte
• k₁ = 1 pour le mode fondamental (mode le plus bas)
