📚 Exercice 14 — Analyse dimensionnelle

Définitions • Utilités • Vrai ou Faux

Partie 1 — Définitions

PHYSIQUE
1) Définir : Dimension d'une grandeur physique, Équation aux dimensions, Exposant dimensionnel, Analyse dimensionnelle.
Dimension

Expression qui indique la composition d'une grandeur physique en termes de grandeurs de base. Ex : [v] = L·T⁻¹, [F] = M·L·T⁻²

Équation aux dimensions

Égalité reliant les dimensions des deux membres d'une relation physique. Ex : [F] = [m]·[a] → M·L·T⁻² = M·L·T⁻²

Exposant dimensionnel

Puissance (exposant) de chaque grandeur de base dans l'équation aux dimensions. Ex : dans [F] = M¹·L¹·T⁻² → exposants : 1, 1, -2

Analyse dimensionnelle

Méthode qui utilise les dimensions des grandeurs pour vérifier la cohérence d'une équation physique ou déduire une relation.

Grandeurs de base (Système International) :
[L] Longueur | [M] Masse | [T] Temps | [I] Courant | [Θ] Température | [N] Quantité de matière | [J] Intensité lumineuse

Partie 2 — Utilités de l'analyse dimensionnelle

PHYSIQUE
2) Donner 2 utilisations de l'analyse dimensionnelle.
Utilité 1 : Vérifier l'homogénéité d'une équation
Permet de vérifier qu'une formule est dimensionnellement cohérente (les deux membres ont les mêmes dimensions). Si les dimensions ne correspondent pas, la formule est fausse.
Utilité 2 : Déduire la forme d'une relation physique
Permet de retrouver la structure d'une équation inconnue en utilisant le principe de cohérence dimensionnelle. Ex : retrouver la période d'un pendule T = 2π√(l/g).
⭐ Autres utilités possibles :
• Conversion d'unités entre systèmes
• Vérification de la cohérence d'un résultat calculé
• Détection d'erreurs de calcul ou de formulation

Partie 3 — Vrai ou Faux

PHYSIQUE
3) Répondre Vrai ou Faux :
3-1 — Le symbole d'une dimension est toujours en lettre majuscule VRAI
3-2 — Une grandeur physique peut avoir plusieurs dimensions VRAI
3-3 — La dimension d'un temps est s FAUX
3-4 — Les angles sont des grandeurs sans dimension VRAI
3-5 — Une expression littérale homogène atteste toujours que la formule est juste FAUX
⭐ Explications :
• 3-1 VRAI : L, M, T, I, Θ, N, J (toujours majuscules)
• 3-2 VRAI : ex : [v] = L·T⁻¹, [F] = M·L·T⁻² (2+ dimensions)
• 3-3 FAUX : la dimension est T (T est la dimension), le "s" est l'unité (seconde)
• 3-4 VRAI : angle = m/m (rapport de deux longueurs) → sans dimension
• 3-5 FAUX : l'homogénéité est nécessaire mais pas suffisante. Ex : s = ½v·t et s = v·t sont toutes deux homogènes [L], mais seule une est correcte.
