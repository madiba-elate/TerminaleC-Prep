📚 Exercice 17 — Unités de Planck

Constantes fondamentales • Longueur, masse, temps, température de Planck

Constantes de base

DONNÉES
k = ℏ = h/(2π) = constante de Planck réduite — [ℏ] = M·L²·T⁻¹ (J·s)
c = célérité de la lumière dans le vide — [c] = L·T⁻¹ (m·s⁻¹)
G = constante de gravitation universelle — [G] = M⁻¹·L³·T⁻² (m³·kg⁻¹·s⁻²)
Kb = constante de Boltzmann = 1,380 × 10⁻²³ J·K⁻¹ — [Kb] = M·L²·T⁻²·Θ⁻¹

Partie 1 — Identifier les grandeurs de Planck

PHYSIQUE
Énoncé : Identifier quelle grandeur physique correspond à chacune des trois expressions : √(kG/c⁵), √(kG/c³), √(kc/G).
Méthode : analyse dimensionnelle de chaque expression
[ℏ] = M·L²·T⁻¹  |  [G] = M⁻¹·L³·T⁻²  |  [c] = L·T⁻¹
1a) √(ℏG/c³) → Longueur de Planck (lₚ)
[ℏG/c³] = (M·L²·T⁻¹)(M⁻¹·L³·T⁻²)/(L·T⁻¹)³
= L⁵·T⁻³/(L³·T⁻³) = L²
√(L²) = L → LONGUEUR
lₚ = √(ℏG/c³) ≈ 1,616 × 10⁻³⁵ m
Plus petite longueur physique significative
1b) √(ℏc/G) → Masse de Planck (mₚ)
[ℏc/G] = (M·L²·T⁻¹)(L·T⁻¹)/(M⁻¹·L³·T⁻²)
= M·L³·T⁻²/(M⁻¹·L³·T⁻²) = M²
√(M²) = M → MASSE
mₚ = √(ℏc/G) ≈ 2,176 × 10⁻⁸ kg
Masse de Planck ≈ masse d'une petite particule
1c) √(ℏG/c⁵) → Durée de Planck (tₚ)
[ℏG/c⁵] = (M·L²·T⁻¹)(M⁻¹·L³·T⁻²)/(L·T⁻¹)⁵
= L⁵·T⁻³/(L⁵·T⁻⁵) = T²
√(T²) = T → TEMPS
tₚ = √(ℏG/c⁵) ≈ 5,391 × 10⁻⁴⁴ s
Plus court temps physique significatif
⭐ Récapitulatif des unités de Planck :
• Longueur lₚ = √(ℏG/c³) — plus petite longueur mesurable
• Masse mₚ = √(ℏc/G) — masse la plus petite d'une particule élémentaire
• Temps tₚ = √(ℏG/c⁵) — plus petit intervalle de temps significatif
• Ces constantes définissent les échelles quantico-gravitationnelles

Partie 2 — Température de Planck (Tₚ)

PHYSIQUE
Énoncé : Tₚ s'exprime avec Kb, c et mₚ. Trouver l'expression de Tₚ.
Approche énergétique :
La température de Planck correspond à l'énergie thermique maximale :
E = Kb·Tₚ = mₚ·c² (énergie de repos)
Tₚ = mₚ·c² / Kb
Substitution de mₚ :
mₚ = √(ℏc/G)

Tₚ = √(ℏc/G) · c² / Kb
= c² · √(ℏc/G) / Kb
= (1/Kb) · √(ℏc⁵/G)
Tₚ = (1/Kb) · √(ℏc⁵/G)
Vérification dimensionnelle :
[ℏc⁵/G] = (M·L²·T⁻¹)(L⁵·T⁻⁵)/(M⁻¹·L³·T⁻²) = M²·L⁴·T⁻⁴
√(ℏc⁵/G) = M·L²·T⁻² = énergie
[Tₚ] = (M·L²·T⁻²)/(M·L²·T⁻²·K⁻¹) = K ✓
Tₚ ≈ 1,417 × 10³² K
Température la plus élevée ayant un sens dans les théories physiques actuelles
⭐ Signification physique :
• À T = Tₚ ≈ 10³² K, les effets quantiques et gravitationnels deviennent indissociables
• Correspond à l'état de l'univers à t ≈ 10⁻⁴³ s après le Big Bang
• Au-delà de cette température, nos théories actuelles (relativité + mécanique quantique) ne s'appliquent plus
• Il faudrait une théorie de gravité quantique pour décrire cet état
