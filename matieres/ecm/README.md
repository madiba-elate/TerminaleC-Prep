## 🎯 Objectif Bac

ECM est une matière à **fort rendement** : petit volume, coef 2, mais 40 points faciles si le plan est maîtrisé. Vise **18/20** → 36/40 pts. Tout est basé sur la **méthodologie** (introduction - développement - conclusion) et la maîtrise des concepts des relations internationales.
