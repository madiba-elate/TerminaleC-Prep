📝 Méthodologie épreuve Info — pour 19/20
1. Définitions (mots clés, formulations exactes)
  • 1 terme = 1 phrase : catégorie + exemple (ex: supervisé = exemples + bonne réponse)
  • Épelle les sigles (IA, SI, TCP/IP) et donne un exemple à chaque définition
2. Exercices d'analyse (distinguer, expliquer, illustrer)
  • Toujours justifier : « supervisé car les exemples sont étiquetés »
  • Étapes dans l'ordre : entraînement → test (données non vues) → prédiction
  • 1 idée = 1 exemple concret (Mobile Money, dossiers d'élèves, pannes…)
3. Algorithmique & C (précision syntaxique)
  • Algo : Variables → Lire → Tableau → boucles POUR → Moyenne = Somme/N → Écrire
  • C : const (pas #define), &R dans scanf, %.2f, 4.0/3.0 (jamais 4/3)
Barème indicatif (sur 20) : Connaissances exactes • Démarche justifiée • Résultat (programme/calcul) • Présentation. Sans justification ni exemple → max 12/20.
💡 Conseils pratiques BAC Info
  • Mots-clés obligatoires : supervisé = étiquettes, test = données non vues, modèle, prédiction, const, tableau.
  • Sigles à maîtriser : IA, SI, TCP/IP, SQL — définis chacun en 1 ligne + 1 exemple.
  • Piège n°1 : écrire 4/3 au lieu de 4.0/3.0 en C, ou oublier le & dans scanf.
  • Piège n°2 : confondre supervisé / non supervisé → le test décisif : « les exemples sont-ils étiquetés ? ».
  • Entraînement : 1 exo/semaine (exercice UA 0–UE 1 + exo 13 déjà en stock). Quiz à 80% min avant de passer.
