Principes des modèles d'apprentissage automatique

Définitions • Supervisé vs non supervisé • Entraînement → Test → Prédiction • 4 exemples • Exercice corrigé • 10 flashcards • Quiz 80%

🎯 Objectifs de la leçon
  • Définir : apprentissage supervisé, modèle, prédiction.
  • Distinguer l'apprentissage supervisé du non supervisé.
  • Expliquer les notions d'entraînement, test et prédiction.
  • Illustrer ces modèles par des exemples concrets.
1️⃣ Définitions des mots clés
Apprentissage supervisé : méthode où le programme s'entraîne sur des exemples déjà associés à la bonne réponse, pour prédire cette réponse sur de nouveaux cas.
Modèle : résultat construit par le programme à l'issue de son entraînement, utilisé pour produire ses réponses.
Prédiction : réponse donnée sur un nouveau cas grâce au modèle.
2️⃣ Supervisé vs non supervisé
Supervisé ✅ étiquettesNon supervisé 🔍 regroupement
DonnéesChaque exemple + la bonne réponseAucune réponse fournie
TravailAssocier profil → réponse connueRegrouper seul les données similaires
ExempleDossiers d'élèves étiquetés par filière → prédire la filièreRegrouper des élèves sans savoir ce qui les rapproche

✍️ Exercice (2 questions)

1) Propose un exemple personnel (futur métier) : domaine + type d'apprentissage justifié.

2) Sur une application supervisée, identifie entraînement, test, prédiction.

✅ Voir le corrigé type

Q1 — modèle : détection des fraudes Mobile Money (futur métier data) → supervisé, car transactions étiquetées « frauduleuse / légitime ». Domaine (1 pt) + type (1 pt) + justification par les étiquettes (2 pts).

  • Entraînement : milliers de transactions passées étiquetées → construction du modèle.
  • Test : taux de bonnes détections sur transactions récentes jamais vues.
  • Prédiction : chaque nouvelle transaction classée en temps réel → alerte/blocage.

⭐ Phrases qui rapportent : « supervisé car les exemples sont étiquetés » / « test sur données non utilisées pour apprendre ».
